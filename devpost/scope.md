# FirstShip scope
## The Unique Kernel
A beginner brings their own app idea; FirstShip reduces it to one finishable workflow and personalizes five days of practice while they build in Codex separately.
## The Core Loop
Describe idea → review/edit reduced scope → approve → copy a tailored task to Codex → build → return, check and reflect → continue. Troubleshooting branches from each task.
## What Working Looks Like
A learner can plan their own idea, complete an exercise with checks, receive stuck guidance, resume after refresh, and download their final summary.
## The POC Boundary
One project, one browser, five available days, one coding tool. Live AI when server credentials are configured; explicit guided fallback otherwise.
## Explicitly Cut
Accounts, payment, direct Codex/repository control, automatic grading, certificates, social features. Hosting optional; public GitHub repository required.

The user approved the displayed detailed FirstShip product plan and asked to start building. This document distills that approved scope using Devpost Learn 2-scope.
